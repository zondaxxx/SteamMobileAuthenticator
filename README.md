# Steam Mobile Authenticator

Минималистичный неофициальный Steam Guard-клиент для Android и iOS. Один Flutter-код отвечает за интерфейс, импорт и создание аутентификатора, QR-вход, подтверждения, инвентарь и локальную историю.

> [!WARNING]
> Это приложение хранит ключи второго фактора. Потеря `maFile` и кода отзыва может привести к потере доступа, а кража файла — к угону аккаунта. Перед использованием сохрани резервную копию и revocation code. Проект не связан с Valve или Steam.

## Что уже работает

- несколько аккаунтов и 5-символьные Steam Guard-коды с таймером;
- импорт обычных `.maFile`;
- импорт SDA-хранилища, зашифрованного PBKDF2-HMAC-SHA1 + AES-256-CBC: нужно одновременно выбрать `manifest.json` и файлы `.maFile`;
- совместимость с современными и частью старых полей сессии SDA;
- получение, принятие и отклонение trade/market confirmations;
- подробности входящих трейдов перед ручным решением;
- обновление Steam access token через refresh token;
- QR-подтверждение входа Steam с проверкой устройства, IP и геолокации;
- пошаговая привязка нового Steam Guard через логин, Guard/e-mail, recovery code и SMS;
- аватарки, актуальные ники и состояние сессии аккаунта;
- просмотр инвентарей Steam, CS2, Dota 2 и TF2 с оценкой по публичным ценам Community Market;
- отдельное opt-in автопринятие, dry-run, allowlist SteamID64 и лимит предметов трейда;
- локальная история ручных и автоматических действий;
- уведомления о новых входящих подтверждениях без секретного preview по умолчанию;
- переносимые резервные копии аккаунтов, настроек и истории с PBKDF2-HMAC-SHA256 + AES-256-GCM;
- светлая/AMOLED-тема, русский/английский язык;
- блокировка Face ID, отпечатком, PIN или код-паролем;
- хранение секретов в Android Keystore и iOS Keychain;
- собственный интерфейс Steam Neo: стеклянные поверхности, свайп-карточки аккаунтов, живой таймер кода, плавные переходы и тактильный отклик;
- отсутствие аналитики, телеметрии и собственных серверов.

## Интерфейс Steam Neo

Версия 1.2 заменяет стандартную Material-компоновку на единый адаптивный дизайн для iOS и Android. Главные разделы открываются через собственную нижнюю панель, аккаунты листаются горизонтальными карточками, а коды, трейды, стоимость инвентаря и история получили контекстные цветовые статусы и мягкие анимации. Светлая и чёрная AMOLED-схемы равноправны; системная настройка уменьшения движения отключает декоративную динамику и сокращает переходы. Статус сессии раскрывается по нажатию и показывает безопасную диагностическую причину без токенов или секретов.

Удаление Steam Guard из приложения пока намеренно не реализовано: для критической операции используй официальный клиент Steam и сохранённый recovery code.

## Импорт

Для незашифрованного аккаунта выбери один или несколько файлов `<steamid>.maFile`.

Для зашифрованного SDA-хранилища:

1. Нажми «Импорт maFile».
2. Выбери `manifest.json` и нужные `.maFile` одним действием.
3. Введи пароль SDA. Пароль используется только во время расшифровки и не сохраняется.

После импорта данные заново сохраняются в системном защищённом хранилище. Не отправляй `maFile`, `manifest.json`, revocation code или содержимое Keychain/Keystore в issues и логи.

## Автоподтверждения

Автопринятие и реальные действия по умолчанию выключены. Сначала работает dry-run: приложение проверяет правила и пишет решение в историю, не отправляя accept. Трейд (`type=2`) может быть принят автоматически только если SteamID64 партнёра удалось извлечь из деталей, он есть в allowlist и число предметов не превышает лимит. Неизвестный партнёр, отсутствие деталей или ошибка сети всегда приводят к пропуску.

Операции маркета (`type=3`) не содержат достаточно надёжных структурированных данных о цене в mobile confirmation. При отключении dry-run и включении автоматизации маркета они принимаются без стоимостного лимита — интерфейс отдельно предупреждает об этом.

Android WorkManager и iOS BGTaskScheduler сами определяют фактический момент фонового запуска. Минимальный интервал — 15 минут. iOS может задержать или полностью пропустить запуск; это ограничение платформы, а не точный планировщик. Открытое приложение и ручное обновление остаются наиболее предсказуемым вариантом.

## Инвентарь и стоимость

Приложение загружает все страницы доступных инвентарей для app/context `753/6`, `730/2`, `570/2` и `440/2`, затем запрашивает публичную минимальную цену каждого уникального marketable-предмета. Итог — оценка, а не гарантированная цена продажи: комиссия, ликвидность и курс не учитываются. Закрытые инвентари, нерыночные предметы и ответы Steam rate limit помечаются как неоценённые; экран всегда показывает покрытие `оценено / всего`, чтобы неполная сумма не выглядела полной.

## Резервная копия и добавление аккаунта

В «Настройки → Данные» можно экспортировать `.smabackup`. Пароль не сохраняется; ключ выводится PBKDF2-HMAC-SHA256 с 250 000 итераций, содержимое защищено AES-256-GCM. Восстановление объединяет аккаунты и историю с локальными данными.

При добавлении нового аутентификатора приложение сохраняет полученный draft в Keychain/Keystore до SMS-финализации и обязательно показывает recovery code. У аккаунта должен быть подтверждённый телефон и не должно быть уже активного мобильного аутентификатора. Пароль Steam используется только для запроса авторизации по HTTPS и не записывается.

## GitHub Actions

Workflow `.github/workflows/mobile-builds.yml` запускает анализ и тесты, затем публикует два артефакта:

- `SteamMobileAuthenticator-Android` — устанавливаемый debug APK;
- `SteamMobileAuthenticator-iOS-unsigned` — unsigned IPA для последующей подписи.

Unsigned IPA нельзя установить на обычное устройство без собственной подписи Apple. Его нужно переподписать через Xcode, Apple Developer account или разрешённую в твоей среде систему sideloading.

Для дополнительного подписанного Android release APK добавь GitHub Actions secrets:

- `ANDROID_KEYSTORE_BASE64`;
- `ANDROID_KEY_ALIAS`;
- `ANDROID_KEYSTORE_PASSWORD`;
- `ANDROID_KEY_PASSWORD`.

Локальная сборка:

```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --debug
flutter build ios --release --no-codesign
```

Проект зафиксирован на Flutter `3.47.1` в CI, Android API 24+ и iOS 15+.

## Безопасность и приватность

Архитектура и принятые ограничения описаны в [SECURITY.md](SECURITY.md), политика данных — в [PRIVACY.md](PRIVACY.md). Любая автоматизация подтверждений снижает защиту от ошибочных или мошеннических операций, поэтому проверяй историю аккаунта и периодически обновляй резервные копии.
